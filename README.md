# nucleo-rtx

STM32G4 Nucleo RTX/CMSIS-RTOSv2 Example

Small Example for the NUCLEOG474RE Board by ST Microelectronics

## Stack

- picolibc
- CMSIS 6
- CMSIS-RTX
- STM32 HAL
